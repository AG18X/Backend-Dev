This branch contains notes and examples related to **Unix/Linux commands, Git version control, and GitHub repository operations**.

---

## 🐧 Unix / Linux Essential Commands

| Command | Description |
|--------|-------------|
| `ls` | List directory contents |
| `ls -a` | List all files including hidden files |
| `pwd` | Print current working directory |
| `cd <dir>` | Change directory |
| `cd ..` | Move to parent directory |
| `mkdir <name>` | Create a new directory |
| `rmdir <name>` | Remove an empty directory |
| `touch <file>` | Create a new file |
| `cat <file>` | Display file content |
| `cp <src> <dest>` | Copy file/folder |
| `mv <old> <new>` | Move/Rename file or folder |
| `rm <file>` | Remove file |
| `rm -r <folder>` | Remove folder recursively |
| `chmod <perm> <file>` | Change file permissions |
| `clear` | Clear terminal screen |
